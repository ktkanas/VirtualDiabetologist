> **Role:** QA Analyst (Muhammad Anas)  
> **Project Type:** Final Year Project | Manual Testing | SQA Portfolio  
> **Domain:** AI-based Healthcare (Diabetes Risk, Retinopathy Detection)  
> **Tech Stack (Under Test):** React, Vite, Flask, LLaMA3, ChromaDB, MongoDB

## 📌 Project Overview

The **Virtual Diabetologist** is an AI-powered chatbot system that offers personalized health recommendations for diabetic users. This testing documentation demonstrates my **SQA knowledge** using industry practices — including software requirement analysis, test planning, writing detailed test cases, and bug reporting — all structured for real-world job readiness.

## 🗂️ Documentation Contents

| `Software_Requirements_Spec.md` | Functional and non-functional requirements of the system |
| `Test_Plan.md` | Test objectives, scope, approach, schedule, deliverables |

| `TC_Negative.md` | Negative test cases: invalid data, wrong formats |
